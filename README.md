# Fortune Cookie for the Liquidated Trader

One fortune-cookie line for a crypto trader who has just been liquidated.
It keeps the cookie voice — "This cookie says…" — names the loss, then
turns it with a double meaning: the market liquidated the coins, but luck
was never leveraged, so there was nothing to liquidate.

## The fortune

> This cookie says the market took your coins, but it could not liquidate your luck, luck was never leveraged.

19 words, 108 characters — inside the 20-word / 160-character gate.

## Run

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` and prints it to stdout. The
program validates the line first (one line, at most 20 words, 1–160
characters) and refuses to write anything that breaks the gate.
